Project Objective

What the project asks

This project explores how women are represented in movies and whether that representation is associated with different measures of movie success.

The analysis focuses on female presence in cast and creative crew roles, then compares these patterns with ratings, audience engagement, and financial outcomes.

Data Sources

What data I used

I used Kaggle datasets as the source for the analysis. The Movies Dataset is the main source for movie metadata, genres, release years, budgets, revenues, cast and crew information, popularity, TMDB ratings, MovieLens ratings, and external IDs.

I then merged this movie data with IMDb/Bechdel information to add IMDb ratings, vote counts, Bechdel ratings, and Bechdel pass status. I also merged Oscar award data by movie title and year to include nomination and win indicators.

Machine Learning

Can representation variables improve prediction?

Machine learning is used as a comparative evaluation method. The models are first trained using standard movie metadata, and representation-related variables are then incorporated to examine whether they improve predictive performance, measured through ROC-AUC scores.

This chart compares how much each representation feature set changes ROC-AUC compared with the controls-only baseline.

The key question is whether representation-related feature groups provide additional predictive value beyond the controls-only baseline, and whether these effects remain consistent across different outcome measures.

  • Rating: Representation variables provide little to no improvement in predicting high IMDb ratings beyond the baseline controls.
  • Engagement: Representation-related variables substantially improve popularity prediction, especially when cast, crew, and Bechdel features are combined.
  • Financial outcomes: The strongest predictive improvement appears in profitability prediction, where the full representation feature set achieves the largest ROC-AUC gain.
  • Overall: Representation variables contribute meaningful predictive value for engagement and financial outcomes, but they are not consistently effective across all measures of movie success.

Conclusion

Final interpretation

This project asked whether female representation in movies is associated with movie success, while treating success as three separate outcomes: ratings, audience engagement, and financial performance. The results show that female representation is connected to movie outcomes, but the answer depends on which type of success is being measured.

  • Movies with female directors do differ from other movies. They tend to have stronger female representation in central cast, lead roles, and crew composition. However, their success outcomes are mixed, so director gender does not point to one single success advantage or disadvantage.
  • Female cast representation is related to success, but weakly. Top-5 female cast share is statistically associated with several outcomes, but the relationships are small and not consistently positive. It describes on-screen balance well, but it is not the strongest success signal.
  • Female crew representation gives the clearest success pattern. Female crew ratio is more consistently connected to audience engagement and selected financial outcomes than to ratings. This suggests that behind-the-camera representation is especially relevant for visibility and market performance.
  • Representation improves prediction selectively. Adding representation variables does not improve high IMDb rating prediction, but the full cast, crew, and Bechdel feature set improves prediction for high popularity and profitability. Representation therefore adds value mainly for engagement and financial success, not for rating success.

Overall, the results show that female representation matters, but not in the same way for every measure of success. Ratings are mixed, engagement shows clearer links, and financial performance becomes easier to predict when representation features are included.
